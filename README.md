<a id="html-q001"></a>
### Q001. What is HTML, and why do we use it?

**✅ Easy answer:** HTML means HyperText Markup Language. It gives a web page its structure using elements such as headings, paragraphs, links and images. CSS handles appearance, and JavaScript handles behaviour.

**💻 Example:**

```html
<h1>Welcome</h1>
<p>This is my first web page.</p>
```

> 💡 **Interview tip:** Do not call HTML a programming language; it is a markup language.

---

<a id="html-q002"></a>
### Q002. What is HTML5?

**✅ Easy answer:** HTML5 is the widely used modern HTML standard. It introduced semantic elements, native audio/video and improved forms. Today, HTML is maintained as a living standard rather than a fixed versioned product.

**💻 Example:**

```html
<main>
  <article>Modern, meaningful markup</article>
</main>
```

> 💡 **Interview tip:** Explain features, not just the number 5.

---

<a id="html-q003"></a>
### Q003. What does `<!DOCTYPE html>` do?

**✅ Easy answer:** It tells browsers to render the document in standards mode. Without a suitable doctype, browsers may use quirks mode and display layouts differently.

**💻 Example:**

```html
<!DOCTYPE html>
<html lang="en">
  <head><title>Demo</title></head>
  <body>Hello!</body>
</html>
```

> 💡 **Interview tip:** The doctype is a declaration, not an HTML element.

---

<a id="html-q004"></a>
### Q004. What is the basic structure of an HTML page?

**✅ Easy answer:** A typical page uses `html` as the root, `head` for metadata and `body` for visible page content. This makes the document readable for browsers and tools.

**💻 Example:**

```html
<!DOCTYPE html>
<html lang="en">
<head>
  <meta charset="UTF-8">
  <title>My Page</title>
</head>
<body><h1>Hello</h1></body>
</html>
```

> 💡 **Interview tip:** Keep metadata inside `head`, not in the visible `body`.

---

<a id="html-q005"></a>
### Q005. Why is the `lang` attribute important?

**✅ Easy answer:** The `lang` attribute identifies the main language of a document. Screen readers can choose appropriate pronunciation, and translation tools understand the page better.

**💻 Example:**

```html
<html lang="en">
  <body><p>Hello, world!</p></body>
</html>
```

> 💡 **Interview tip:** Set `lang` even when the whole site uses only English.

---

<a id="html-q006"></a>
### Q006. What does `<meta charset="UTF-8">` do?

**✅ Easy answer:** It declares the document's character encoding. UTF-8 supports English, Hindi and many other languages, helping text display correctly.

**💻 Example:**

```html
<meta charset="UTF-8">
<p>नमस्ते, Jamshed!</p>
```

> 💡 **Interview tip:** Place charset metadata near the beginning of `head`.

---

<a id="html-q007"></a>
### Q007. Why do we use the viewport meta tag?

**✅ Easy answer:** It helps mobile browsers size the viewport to the device width. Without it, mobile pages may look zoomed out even when your CSS is responsive.

**💻 Example:**

```html
<meta name="viewport" content="width=device-width, initial-scale=1">
```

> 💡 **Interview tip:** Responsive CSS and the viewport tag work together.

---

<a id="html-q008"></a>
### Q008. What is the purpose of the `<title>` element?

**✅ Easy answer:** The `title` gives the document a meaningful name. Browsers display it in tabs, and search engines may use it when showing a result.

**💻 Example:**

```html
<head>
  <title>HTML Interview Questions | Code with Jamshed</title>
</head>
```

> 💡 **Interview tip:** Write a unique and descriptive title for each important page.

---

<a id="html-q009"></a>
### Q009. How do you write comments in HTML?

**✅ Easy answer:** Comments let you leave notes for developers without showing them as page content. They are still visible in the page source, so never put secrets inside.

**💻 Example:**

```html
<!-- Main navigation starts here -->
<nav><a href="/">Home</a></nav>
```

> 💡 **Interview tip:** Comments do not protect confidential information.

---

<a id="html-q010"></a>
### Q010. What is the difference between an HTML element and an attribute?

**✅ Easy answer:** An element defines a part of the page, while an attribute gives that element extra information or behaviour. In a link, `a` is the element and `href` is an attribute.

**💻 Example:**

```html
<a href="/about" title="About our team">About</a>
```

> 💡 **Interview tip:** Attribute values should be quoted for clarity.

## 🧱 HTML5 Topic 02: Semantic HTML & Document Structure

<sub>Questions 011–020 · [Back to contents](#table-of-contents)</sub>

<a id="html-q011"></a>
### Q011. What is semantic HTML?

**✅ Easy answer:** Semantic HTML uses tags that describe meaning, such as `main`, `article` and `nav`, rather than using `div` for everything. It improves accessibility and maintainability.

**💻 Example:**

```html
<main>
  <article><h2>News</h2><p>Latest update</p></article>
</main>
```

> 💡 **Interview tip:** Choose the element by meaning, not its default styling.

---

<a id="html-q012"></a>
### Q012. When should you use `<header>`?

**✅ Easy answer:** Use `header` for introductory content such as a heading, logo or navigation related to a page or section. A page may contain more than one header.

**💻 Example:**

```html
<header>
  <h1>Developer Notes</h1>
  <p>Learn HTML the easy way.</p>
</header>
```

> 💡 **Interview tip:** A `header` inside an `article` belongs to that article.

---

<a id="html-q013"></a>
### Q013. What is the role of `<nav>`?

**✅ Easy answer:** The `nav` element identifies a major block of navigation links. It helps assistive technology jump to site navigation quickly.

**💻 Example:**

```html
<nav aria-label="Primary">
  <a href="/">Home</a>
  <a href="/courses">Courses</a>
</nav>
```

> 💡 **Interview tip:** Use `nav` for important navigation, not every random link.

---

<a id="html-q014"></a>
### Q014. Why should a page normally have one `<main>`?

**✅ Easy answer:** The `main` element marks the dominant, unique page content. A page should generally expose one main landmark, so screen reader users can move straight to it.

**💻 Example:**

```html
<header>Site header</header>
<main id="content"><h1>Dashboard</h1></main>
```

> 💡 **Interview tip:** Keep repeating site menus outside `main`.

---

<a id="html-q015"></a>
### Q015. How are `<section>` and `<article>` different?

**✅ Easy answer:** A `section` groups related content by theme; an `article` represents a self-contained item that could make sense on its own, like a blog post.

**💻 Example:**

```html
<section aria-labelledby="latest">
  <h2 id="latest">Latest posts</h2>
  <article><h3>React Tips</h3><p>Read more...</p></article>
</section>
```

> 💡 **Interview tip:** A section usually benefits from a meaningful heading.

---

<a id="html-q016"></a>
### Q016. When do you use `<aside>`?

**✅ Easy answer:** Use `aside` for content indirectly related to the surrounding main content, such as a sidebar, glossary or related links.

**💻 Example:**

```html
<article>
  <h2>CSS Grid</h2>
  <p>Main tutorial...</p>
  <aside>Related: Flexbox guide</aside>
</article>
```

> 💡 **Interview tip:** `aside` means complementary content, not necessarily right-side layout.

---

<a id="html-q017"></a>
### Q017. What should go inside `<footer>`?

**✅ Easy answer:** A `footer` typically contains author details, copyright, policies or related links for a page or section. An article can have its own footer.

**💻 Example:**

```html
<footer>
  <p>© 2026 Code with Jamshed</p>
</footer>
```

> 💡 **Interview tip:** Do not use `footer` only because something appears at the bottom visually.

---

<a id="html-q018"></a>
### Q018. How should heading levels `<h1>` to `<h6>` be used?

**✅ Easy answer:** Headings describe the outline of content. Start with a clear page heading, then nest sections logically (`h2`, `h3`, etc.) instead of choosing levels for visual size.

**💻 Example:**

```html
<h1>HTML Guide</h1>
<h2>Forms</h2>
<h3>Validation</h3>
```

> 💡 **Interview tip:** Use CSS for font size; do not pick heading tags only for appearance.

---

<a id="html-q019"></a>
### Q019. What is the difference between `<div>` and `<span>`?

**✅ Easy answer:** Both are generic containers without special meaning. `div` is commonly used for block-level grouping; `span` is for grouping small inline text.

**💻 Example:**

```html
<div class="card">
  <p>Price: <span class="amount">₹499</span></p>
</div>
```

> 💡 **Interview tip:** Prefer a semantic tag when one exists.

---

<a id="html-q020"></a>
### Q020. How do `<strong>` and `<em>` differ from `<b>` and `<i>`?

**✅ Easy answer:** `strong` marks strong importance and `em` marks stress emphasis. `b` draws attention without importance; `i` offsets text, such as a technical term.

**💻 Example:**

```html
<p><strong>Warning:</strong> Save your work.</p>
<p>You <em>must</em> read the instructions.</p>
```

> 💡 **Interview tip:** Semantic meaning matters for accessibility.

## 🧱 HTML5 Topic 03: Links, Images & Media

<sub>Questions 021–030 · [Back to contents](#table-of-contents)</sub>

<a id="html-q021"></a>
### Q021. What does the `<p>` element represent?

**✅ Easy answer:** The `p` element marks a paragraph of prose. Browsers add default spacing, but you should control visual spacing with CSS.

**💻 Example:**

```html
<p>HTML creates structure.</p>
<p>CSS makes the page beautiful.</p>
```

> 💡 **Interview tip:** Do not use repeated `br` elements to separate paragraphs.

---

<a id="html-q022"></a>
### Q022. How do hyperlinks work in HTML?

**✅ Easy answer:** Use `a` with `href` to point to a page, resource, section or URL. The link text should clearly describe the destination.

**💻 Example:**

```html
<a href="https://developer.mozilla.org/">Read MDN docs</a>
```

> 💡 **Interview tip:** Avoid vague link text like “click here” when possible.

---

<a id="html-q023"></a>
### Q023. What is the difference between absolute and relative URLs?

**✅ Easy answer:** An absolute URL includes a scheme and host. A relative URL resolves against the current document's base URL and is useful for internal navigation.

**💻 Example:**

```html
<a href="https://example.com/docs">Absolute</a>
<a href="/docs">Relative from site root</a>
```

> 💡 **Interview tip:** Prefer root-relative paths for predictable internal site links.

---

<a id="html-q024"></a>
### Q024. Why is `alt` text used on images?

**✅ Easy answer:** An image's `alt` attribute provides a text alternative when the image cannot be seen. Describe useful meaning; use `alt=""` for purely decorative images.

**💻 Example:**

```html
<img src="team.jpg" alt="Four developers discussing a design">
```

> 💡 **Interview tip:** Do not start every alt text with “Image of”.

---

<a id="html-q025"></a>
### Q025. What is the `<picture>` element?

**✅ Easy answer:** `picture` lets the browser choose between image sources based on format or media conditions. The fallback `img` is required for display and alt text.

**💻 Example:**

```html
<picture>
  <source media="(max-width: 600px)" srcset="portrait.jpg">
  <img src="landscape.jpg" alt="Mountain view">
</picture>
```

> 💡 **Interview tip:** Use `picture` for art direction, such as a different mobile crop.

---

<a id="html-q026"></a>
### Q026. What do `srcset` and `sizes` do?

**✅ Easy answer:** `srcset` offers image candidates with different widths. `sizes` tells the browser how wide the image will display, helping it download an appropriate source.

**💻 Example:**

```html
<img src="photo-600.jpg"
     srcset="photo-600.jpg 600w, photo-1200.jpg 1200w"
     sizes="(max-width: 700px) 100vw, 600px"
     alt="Conference audience">
```

> 💡 **Interview tip:** Width descriptors work together with a correct `sizes` attribute.

---

<a id="html-q027"></a>
### Q027. What does `loading="lazy"` mean for images?

**✅ Easy answer:** It hints that the browser can postpone loading off-screen images until they are near the viewport. This can save bandwidth on long pages.

**💻 Example:**

```html
<img src="gallery-08.jpg" alt="Gallery photo" loading="lazy" width="800" height="600">
```

> 💡 **Interview tip:** Do not lazy-load the main above-the-fold hero image.

---

<a id="html-q028"></a>
### Q028. What are `<figure>` and `<figcaption>` used for?

**✅ Easy answer:** `figure` groups self-contained content such as an image, chart or code sample, and `figcaption` gives that content an accessible caption.

**💻 Example:**

```html
<figure>
  <img src="chart.png" alt="Sales increased from January to March">
  <figcaption>Quarterly sales growth</figcaption>
</figure>
```

> 💡 **Interview tip:** Caption and alt text serve different purposes.

---

<a id="html-q029"></a>
### Q029. How can you add audio to an HTML page?

**✅ Easy answer:** The `audio` element plays sound natively. Add `controls` for a browser-provided player and include fallback text.

**💻 Example:**

```html
<audio controls>
  <source src="lesson.mp3" type="audio/mpeg">
  Your browser does not support audio.
</audio>
```

> 💡 **Interview tip:** Do not rely on autoplay; browsers often restrict it.

---

<a id="html-q030"></a>
### Q030. How can you add video and subtitles?

**✅ Easy answer:** Use `video` with `controls`, one or more sources, and `track` for captions or subtitles. Captions make the content more accessible.

**💻 Example:**

```html
<video controls width="480">
  <source src="demo.mp4" type="video/mp4">
  <track src="captions.vtt" kind="captions" srclang="en" label="English">
</video>
```

> 💡 **Interview tip:** Provide captions for important spoken content.

## 🧱 HTML5 Topic 04: Forms: Essentials

<sub>Questions 031–040 · [Back to contents](#table-of-contents)</sub>

<a id="html-q031"></a>
### Q031. What is the `<form>` element?

**✅ Easy answer:** A `form` groups controls and defines where/how submitted values are sent. It uses attributes such as `action` and `method`.

**💻 Example:**

```html
<form action="/signup" method="post">
  <input name="email" type="email" required>
  <button type="submit">Join</button>
</form>
```

> 💡 **Interview tip:** Inputs need a `name` to be included in normal form submission.

---

<a id="html-q032"></a>
### Q032. How are GET and POST different in forms?

**✅ Easy answer:** GET sends form data in the URL query string and is suitable for non-sensitive searches. POST sends data in the request body and is appropriate for operations that change data.

**💻 Example:**

```html
<form action="/search" method="get">
  <input name="q">
  <button>Search</button>
</form>
```

> 💡 **Interview tip:** POST does not itself encrypt data; use HTTPS.

---

<a id="html-q033"></a>
### Q033. Why should an input have a `<label>`?

**✅ Easy answer:** A label gives a control an accessible name and increases its clickable area. Match `for` with the input's `id`, or wrap the input inside the label.

**💻 Example:**

```html
<label for="email">Email address</label>
<input id="email" name="email" type="email">
```

> 💡 **Interview tip:** Placeholder text is not a replacement for a label.

---

<a id="html-q034"></a>
### Q034. What are useful HTML input types?

**✅ Easy answer:** Input types like `email`, `number`, `date` and `password` help browsers provide relevant keyboards, validation and UI. Choose based on the data you expect.

**💻 Example:**

```html
<input type="email" name="email">
<input type="date" name="startDate">
<input type="password" name="password">
```

> 💡 **Interview tip:** `type="number"` is not suitable for phone numbers or PINs.

---

<a id="html-q035"></a>
### Q035. How does built-in form validation work?

**✅ Easy answer:** Attributes such as `required`, `min`, `max` and `type` let the browser check common constraints before submission. Server-side validation is still necessary.

**💻 Example:**

```html
<input type="number" name="age" min="18" max="65" required>
```

> 💡 **Interview tip:** Client-side validation improves UX but is not a security boundary.

---

<a id="html-q036"></a>
### Q036. What does the `pattern` attribute do?

**✅ Easy answer:** For applicable text-like inputs, `pattern` defines a regular expression the full input value must match. Use it with a clear help message.

**💻 Example:**

```html
<label for="pin">4-digit PIN</label>
<input id="pin" name="pin" pattern="[0-9]{4}" title="Enter exactly 4 digits" required>
```

> 💡 **Interview tip:** Use `inputmode="numeric"` if you also want a numeric mobile keyboard.

---

<a id="html-q037"></a>
### Q037. What is the difference between `placeholder` and `value`?

**✅ Easy answer:** `placeholder` shows a temporary hint in an empty input. `value` sets the actual initial field value, which can be submitted if unchanged.

**💻 Example:**

```html
<input name="city" placeholder="Enter city">
<input name="country" value="India">
```

> 💡 **Interview tip:** Never use placeholder as the only field label.

---

<a id="html-q038"></a>
### Q038. What is the difference between `<select>` and `<datalist>`?

**✅ Easy answer:** `select` limits selection to defined options. `datalist` suggests values for an input but usually allows the user to enter something else.

**💻 Example:**

```html
<select name="level"><option>Beginner</option><option>Advanced</option></select>
<input list="cities" name="city">
<datalist id="cities"><option value="Lucknow"><option value="Delhi"></datalist>
```

> 💡 **Interview tip:** Choose `select` when you need a controlled set of choices.

---

<a id="html-q039"></a>
### Q039. What do `<fieldset>` and `<legend>` provide?

**✅ Easy answer:** `fieldset` groups related form controls; `legend` gives the group a meaningful name. This is especially useful for radio button groups.

**💻 Example:**

```html
<fieldset>
  <legend>Choose plan</legend>
  <label><input type="radio" name="plan" value="basic"> Basic</label>
  <label><input type="radio" name="plan" value="pro"> Pro</label>
</fieldset>
```

> 💡 **Interview tip:** Radio buttons in the same group share the same `name`.

---

<a id="html-q040"></a>
### Q040. Why should buttons have an explicit `type`?

**✅ Easy answer:** Inside a form, a `button` defaults to `submit`. Set `type="button"` for actions that should not submit the form, or `type="reset"` to restore initial values.

**💻 Example:**

```html
<form>
  <button type="button" onclick="alert('Preview')">Preview</button>
  <button type="submit">Save</button>
</form>
```

> 💡 **Interview tip:** Unexpected form submissions often come from missing button types.

---

## 🧱 HTML5 Topic 05: Forms: Advanced Behaviour

<sub>Questions 041–050 · [Back to contents](#table-of-contents)</sub>

<a id="html-q041"></a>
### Q041. What does `autocomplete` do?

**✅ Easy answer:** The `autocomplete` attribute tells browsers what data a field expects, allowing relevant autofill suggestions. Use tokens like `name`, `email` and `current-password` correctly.

**💻 Example:**

```html
<input name="email" type="email" autocomplete="email">
<input name="password" type="password" autocomplete="current-password">
```

> 💡 **Interview tip:** Use `new-password` for a password being created.

---

<a id="html-q042"></a>
### Q042. How do `disabled` and `readonly` differ?

**✅ Easy answer:** A disabled control is generally unfocusable and not submitted with a form. A readonly text control can usually receive focus and is submitted, but users cannot edit it.

**💻 Example:**

```html
<input name="user" value="jamshed" readonly>
<input name="internal" value="123" disabled>
```

> 💡 **Interview tip:** Do not depend on either attribute for security.

---

<a id="html-q043"></a>
### Q043. Why is the `name` attribute important in a form?

**✅ Easy answer:** When a form is submitted, successful controls are identified by their `name`. An `id` is useful for labels and DOM hooks but does not replace `name`.

**💻 Example:**

```html
<form action="/search">
  <label for="term">Search</label>
  <input id="term" name="q">
  <button>Go</button>
</form>
```

> 💡 **Interview tip:** Without `name="q"`, the browser would not submit the search parameter.

---

<a id="html-q044"></a>
### Q044. When do you use `enctype="multipart/form-data"`?

**✅ Easy answer:** Use this encoding for form submissions that include uploaded files. The browser formats the request body with separate parts for fields and file data.

**💻 Example:**

```html
<form action="/upload" method="post" enctype="multipart/form-data">
  <input type="file" name="resume">
  <button>Upload</button>
</form>
```

> 💡 **Interview tip:** File uploads must still be validated and safely handled by the server.

---

<a id="html-q045"></a>
### Q045. How do `minlength` and `maxlength` work?

**✅ Easy answer:** For supported text-like controls, `minlength` sets a minimum number of characters and `maxlength` limits the allowed length. They differ from number-input `min` and `max`.

**💻 Example:**

```html
<input type="text" name="username" minlength="3" maxlength="20" required>
```

> 💡 **Interview tip:** Character limits are not a substitute for server validation.

---

<a id="html-q046"></a>
### Q046. What does `novalidate` do on a form?

**✅ Easy answer:** It disables the browser's interactive constraint-validation step during form submission. You may use it when your own validation UI is implemented.

**💻 Example:**

```html
<form novalidate>
  <input type="email" name="email" required>
  <button>Submit</button>
</form>
```

> 💡 **Interview tip:** With `novalidate`, implement and test your own error feedback.

---

<a id="html-q047"></a>
### Q047. What is the purpose of `inputmode`?

**✅ Easy answer:** `inputmode` hints which virtual keyboard should appear on mobile devices. It does not change the data type or automatically validate input.

**💻 Example:**

```html
<label for="otp">OTP</label>
<input id="otp" name="otp" inputmode="numeric" pattern="[0-9]{6}" maxlength="6">
```

> 💡 **Interview tip:** `inputmode` is a keyboard hint, not a validation rule.

---

<a id="html-q048"></a>
### Q048. What is the `<output>` element?

**✅ Easy answer:** `output` represents the result of a calculation or user action. It can be connected to form inputs to present a calculated value.

**💻 Example:**

```html
<form oninput="this.elements.total.value = Number(this.elements.qty.value) * 50">
  <input name="qty" type="number" value="2" min="0">
  <output name="total" for="qty">100</output>
</form>
```

> 💡 **Interview tip:** For production apps, keep logic in JavaScript rather than large inline handlers.

---

<a id="html-q049"></a>
### Q049. How are `<progress>` and `<meter>` different?

**✅ Easy answer:** `progress` represents completion of a task, while `meter` displays a measured value within a known range, such as storage usage.

**💻 Example:**

```html
<label for="upload">Upload progress</label>
<progress id="upload" value="70" max="100">70%</progress>
<label for="storage">Storage</label>
<meter id="storage" min="0" max="100" value="75">75%</meter>
```

> 💡 **Interview tip:** Use `progress` for tasks and `meter` for measurements.

---

<a id="html-q050"></a>
### Q050. How do `checkValidity()` and `reportValidity()` differ?

**✅ Easy answer:** Both check HTML form constraints. `checkValidity()` returns a boolean, while `reportValidity()` also asks the browser to display validation feedback for invalid controls.

**💻 Example:**

```js
const form = document.querySelector('form');
if (!form.checkValidity()) form.reportValidity();
```

> 💡 **Interview tip:** Remember to validate again on the backend.

## 🧱 HTML5 Topic 06: Lists, Tables & Interactive Elements

<sub>Questions 051–060 · [Back to contents](#table-of-contents)</sub>

<a id="html-q051"></a>
### Q051. How are `<ul>`, `<ol>` and `<dl>` different?

**✅ Easy answer:** `ul` makes an unordered list, `ol` makes an ordered list, and `dl` pairs terms with descriptions. Use whichever matches the content's meaning.

**💻 Example:**

```html
<ul><li>HTML</li><li>CSS</li></ul>
<ol><li>Learn</li><li>Practise</li></ol>
<dl><dt>API</dt><dd>Application Programming Interface</dd></dl>
```

> 💡 **Interview tip:** Do not choose list tags only to get bullets or numbers.

---

<a id="html-q052"></a>
### Q052. How do you create a table in HTML?

**✅ Easy answer:** Use `table` for tabular information, `tr` for rows, `th` for header cells and `td` for data cells. Avoid tables for overall page layout.

**💻 Example:**

```html
<table>
  <tr><th scope="col">Name</th><th scope="col">Score</th></tr>
  <tr><td>Asha</td><td>90</td></tr>
</table>
```

> 💡 **Interview tip:** Use tables only when data has rows and columns.

---

<a id="html-q053"></a>
### Q053. What are `<thead>`, `<tbody>` and `<tfoot>`?

**✅ Easy answer:** These elements group header, body and footer rows in a table. They make large data tables easier to structure and style.

**💻 Example:**

```html
<table>
  <thead><tr><th scope="col">Item</th></tr></thead>
  <tbody><tr><td>Keyboard</td></tr></tbody>
  <tfoot><tr><td>Total: 1</td></tr></tfoot>
</table>
```

> 💡 **Interview tip:** Browsers may repeat table headers when printing multi-page tables.

---

<a id="html-q054"></a>
### Q054. Why do we use `scope` on table headings?

**✅ Easy answer:** The `scope` attribute tells assistive technologies whether a header applies to a row or column. This helps users understand data relationships.

**💻 Example:**

```html
<table>
  <tr><th scope="col">Topic</th><th scope="col">Level</th></tr>
  <tr><th scope="row">HTML</th><td>Beginner</td></tr>
</table>
```

> 💡 **Interview tip:** For complex tables, more explicit header associations may be needed.

---

<a id="html-q055"></a>
### Q055. What is the purpose of `<caption>` in tables?

**✅ Easy answer:** `caption` gives a table a clear title, helping both sighted users and screen reader users understand its purpose.

**💻 Example:**

```html
<table>
  <caption>Monthly attendance</caption>
  <tr><th scope="col">Month</th><th scope="col">Days</th></tr>
  <tr><td>April</td><td>22</td></tr>
</table>
```

> 💡 **Interview tip:** Put `caption` as the first child of `table`.

---

<a id="html-q056"></a>
### Q056. How do `rowspan` and `colspan` work?

**✅ Easy answer:** `rowspan` makes a cell cover multiple rows, while `colspan` makes a cell cover multiple columns. Use them when your data genuinely needs merged cells.

**💻 Example:**

```html
<table>
  <tr><th colspan="2">Contact</th></tr>
  <tr><td>Email</td><td>hello@example.com</td></tr>
</table>
```

> 💡 **Interview tip:** Merged cells can complicate accessibility; use only when needed.

---

<a id="html-q057"></a>
### Q057. What is the `<template>` element?

**✅ Easy answer:** `template` holds HTML markup that is not rendered immediately. JavaScript can clone its content to create repeated UI elements.

**💻 Example:**

```html
<template id="card-template">
  <article class="card"><h2>New card</h2></article>
</template>
<script>
  document.body.append(document.querySelector('#card-template').content.cloneNode(true));
</script>
```

> 💡 **Interview tip:** The template's content lives in a document fragment until used.

---

<a id="html-q058"></a>
### Q058. How do `<details>` and `<summary>` work?

**✅ Easy answer:** They provide an accessible native disclosure widget. `summary` is the clickable heading, and `details` contains content shown when expanded.

**💻 Example:**

```html
<details>
  <summary>What is HTML?</summary>
  <p>A markup language for web content.</p>
</details>
```

> 💡 **Interview tip:** Great for FAQs without writing custom toggle JavaScript.

---

<a id="html-q059"></a>
### Q059. What is the `<dialog>` element?

**✅ Easy answer:** `dialog` represents a dialog box. Calling `showModal()` opens it as a modal; users can generally close it through native keyboard interaction, depending on setup.

**💻 Example:**

```html
<dialog id="confirm"><p>Delete this item?</p><button onclick="document.getElementById('confirm').close()">Cancel</button></dialog>
<button onclick="document.getElementById('confirm').showModal()">Open</button>
```

> 💡 **Interview tip:** For production, use an explicit DOM reference instead of relying on element IDs as globals.

---

<a id="html-q060"></a>
### Q060. How does the `hidden` attribute work?

**✅ Easy answer:** `hidden` marks content as not currently relevant and browsers normally do not render it. Do not use hidden content to store secrets.

**💻 Example:**

```html
<p hidden>This note is currently not relevant.</p>
```

> 💡 **Interview tip:** CSS can override the display of hidden content, so test your styles.

<a id="html-topic-07"></a>
## 🧱 HTML5 Topic 07: Accessibility & ARIA

<sub>Questions 061–070 · [Back to contents](#table-of-contents)</sub>

<a id="html-q061"></a>
### Q061. What does web accessibility mean?

**✅ Easy answer:** Accessibility means people can use a website regardless of disability, device or input method. Use semantic elements, keyboard support, clear labels and sufficient contrast.

**💻 Example:**

```html
<button type="button">Save changes</button>
```

> 💡 **Interview tip:** Start with native HTML controls before adding ARIA.

---

<a id="html-q062"></a>
### Q062. When should decorative images use `alt=""`?

**✅ Easy answer:** If an image adds no useful meaning, an empty alt value tells screen readers to skip its description. This avoids unnecessary noise.

**💻 Example:**

```html
<img src="divider.svg" alt="">
```

> 💡 **Interview tip:** A meaningful product photo needs useful alt text, not an empty one.

---

<a id="html-q063"></a>
### Q063. What is an accessible name?

**✅ Easy answer:** An accessible name is the text assistive technology uses to identify a control. It can come from a visible label, button text or selected ARIA attributes.

**💻 Example:**

```html
<label for="search">Search topics</label>
<input id="search" type="search">
```

> 💡 **Interview tip:** Prefer a visible label instead of adding `aria-label` everywhere.

---

<a id="html-q064"></a>
### Q064. When should you use `aria-label`?

**✅ Easy answer:** Use `aria-label` to provide an accessible name when a visible label is missing, such as for an icon-only button. It does not replace proper visible instructions.

**💻 Example:**

```html
<button type="button" aria-label="Close dialog">×</button>
```

> 💡 **Interview tip:** Use meaningful words like “Close dialog”, not vague names like “button”.

---

<a id="html-q065"></a>
### Q065. What is the `role` attribute?

**✅ Easy answer:** ARIA roles describe what an element does for assistive technology. Native HTML already has built-in semantics, so add `role` only when genuinely needed.

**💻 Example:**

```html
<div role="status">Your changes are saved.</div>
```

> 💡 **Interview tip:** Prefer `<button>` to `<div role="button">` because buttons handle keyboard interaction.

---

<a id="html-q066"></a>
### Q066. What does `tabindex` do?

**✅ Easy answer:** `tabindex="0"` puts certain elements in normal keyboard tab order; `-1` allows programmatic focus without normal tab navigation. Positive values are usually best avoided.

**💻 Example:**

```html
<main id="content" tabindex="-1"><h1>Article</h1></main>
```

> 💡 **Interview tip:** Avoid positive tabindex values that create confusing focus order.

---

<a id="html-q067"></a>
### Q067. What is a skip link?

**✅ Easy answer:** A skip link helps keyboard users jump past repeated navigation directly to page content. It typically targets a `main` element.

**💻 Example:**

```html
<a href="#content">Skip to main content</a>
<nav>Menu links...</nav>
<main id="content"><h1>Welcome</h1></main>
```

> 💡 **Interview tip:** Style skip links so they become visible when focused.

---

<a id="html-q068"></a>
### Q068. What are landmark elements?

**✅ Easy answer:** Landmarks such as `header`, `nav`, `main` and `footer` expose meaningful page regions to assistive technology. Users can navigate those regions quickly.

**💻 Example:**

```html
<header>Logo</header>
<nav aria-label="Primary">Menu</nav>
<main><h1>Course</h1></main>
<footer>Contact</footer>
```

> 💡 **Interview tip:** Add labels if there are multiple landmarks of the same kind.

---

<a id="html-q069"></a>
### Q069. How can you make a UI keyboard friendly?

**✅ Easy answer:** Use native interactive elements in a sensible document order, keep visible focus styles, and ensure actions work with Enter or Space as appropriate.

**💻 Example:**

```html
<button type="button" onclick="alert('Saved')">Save</button>
```

> 💡 **Interview tip:** A clickable `div` needs extra keyboard behaviour; a button already has it.

---

<a id="html-q070"></a>
### Q070. What is an ARIA live region?

**✅ Easy answer:** A live region lets assistive technologies announce updated text without moving focus. `role="status"` is suitable for many non-urgent status messages.

**💻 Example:**

```html
<p id="message" role="status" aria-live="polite"></p>
<button onclick="document.getElementById('message').textContent='Saved successfully'">Save</button>
```

> 💡 **Interview tip:** Do not announce every small update or users may get overwhelmed.

## 🧱 HTML5 Topic 08: Browser Features & Script Loading

<sub>Questions 071–080 · [Back to contents](#table-of-contents)</sub>

<a id="html-q071"></a>
### Q071. What are `data-*` attributes?

**✅ Easy answer:** Custom `data-*` attributes store small, application-specific string values on elements. JavaScript can access them through the element's `dataset` property.

**💻 Example:**

```html
<button data-product-id="42" id="buy">Buy</button>
<script>console.log(document.querySelector('#buy').dataset.productId);</script>
```

> 💡 **Interview tip:** Treat dataset content as untrusted input, not as secure data.

---

<a id="html-q072"></a>
### Q072. What does `contenteditable` do?

**✅ Easy answer:** It allows users to edit text inside an element in the browser. It does not automatically save changes to the server.

**💻 Example:**

```html
<p contenteditable="true">Click to edit this note.</p>
```

> 💡 **Interview tip:** Sanitise user-edited HTML before storing or rendering it elsewhere.

---

<a id="html-q073"></a>
### Q073. What does `draggable` do?

**✅ Easy answer:** Setting `draggable="true"` enables native dragging of an element. A complete drag-and-drop UI also needs JavaScript events and an accessible alternative.

**💻 Example:**

```html
<div draggable="true">Drag me</div>
```

> 💡 **Interview tip:** Dragging alone does not create a functional drop target.

---

<a id="html-q074"></a>
### Q074. How do `async` and `defer` differ on scripts?

**✅ Easy answer:** Both can download a classic external script without blocking HTML parsing. `defer` executes after parsing in document order; `async` executes when ready, so order is not guaranteed.

**💻 Example:**

```html
<script src="analytics.js" async></script>
<script src="app.js" defer></script>
```

> 💡 **Interview tip:** `async` and `defer` have different behaviour for module scripts.

---

<a id="html-q075"></a>
### Q075. What does `type="module"` do?

**✅ Easy answer:** A module script can use ES module imports/exports and is deferred by default. Modules have their own scope and follow module-loading rules.

**💻 Example:**

```html
<script type="module">
  import { greet } from './greet.js';
  greet();
</script>
```

> 💡 **Interview tip:** Use a local web server when testing module imports.

---

<a id="html-q076"></a>
### Q076. When is `<noscript>` useful?

**✅ Easy answer:** `noscript` provides alternate content when scripting is unavailable or disabled. It can explain why a JavaScript-dependent feature cannot work.

**💻 Example:**

```html
<noscript>Please enable JavaScript to use the live editor.</noscript>
```

> 💡 **Interview tip:** Use progressive enhancement where possible, instead of blocking the whole site.

---

<a id="html-q077"></a>
### Q077. What is an `<iframe>`?

**✅ Easy answer:** An iframe embeds another browsing context, such as a map or video player, inside a page. Give it a descriptive `title` and restrict permissions as needed.

**💻 Example:**

```html
<iframe src="https://example.com/embed" title="Course preview" loading="lazy"></iframe>
```

> 💡 **Interview tip:** Only embed trusted sources and configure sandbox/permissions carefully.

---

<a id="html-q078"></a>
### Q078. What does the `sandbox` attribute on an iframe do?

**✅ Easy answer:** `sandbox` restricts capabilities of embedded content. You can explicitly grant only the permissions required by the embed.

**💻 Example:**

```html
<iframe src="/preview.html" title="Safe preview" sandbox="allow-scripts"></iframe>
```

> 💡 **Interview tip:** Avoid combining `allow-scripts` and `allow-same-origin` for untrusted same-origin embedded content.

---

<a id="html-q079"></a>
### Q079. What are `<pre>` and `<code>` used for?

**✅ Easy answer:** `code` marks computer code; `pre` preserves whitespace and line breaks. Use them together when showing multi-line source examples.

**💻 Example:**

```html
<pre><code>const total = 5 + 7;
console.log(total);</code></pre>
```

> 💡 **Interview tip:** Escape `<` as `&lt;` when displaying HTML source itself.

---

<a id="html-q080"></a>
### Q080. What does `<meta name="robots">` control?

**✅ Easy answer:** It gives cooperating search engine crawlers indexing directives, such as `noindex`. It is not an access-control mechanism.

**💻 Example:**

```html
<meta name="robots" content="noindex, nofollow">
```

> 💡 **Interview tip:** Sensitive pages require real authentication, not robots directives.

## 🧱 HTML5 Topic 09: SEO, Performance & Security

<sub>Questions 081–090 · [Back to contents](#table-of-contents)</sub>

<a id="html-q081"></a>
### Q081. What is a canonical URL?

**✅ Easy answer:** A canonical link identifies the preferred URL for substantially duplicate or similar pages. It is a search-engine hint, not a guaranteed instruction.

**💻 Example:**

```html
<link rel="canonical" href="https://example.com/guides/html">
```

> 💡 **Interview tip:** Use the canonical URL that should represent the content in search.

---

<a id="html-q082"></a>
### Q082. What is the meta description tag?

**✅ Easy answer:** It provides a short page summary that search engines may use in search snippets. It does not guarantee what the search result displays.

**💻 Example:**

```html
<meta name="description" content="Easy HTML interview questions with examples and answers.">
```

> 💡 **Interview tip:** Describe the page accurately instead of stuffing keywords.

---

<a id="html-q083"></a>
### Q083. What are Open Graph tags?

**✅ Easy answer:** Open Graph metadata gives social platforms a title, description and image to use when sharing links. Platform behaviour varies.

**💻 Example:**

```html
<meta property="og:title" content="HTML Interview Guide">
<meta property="og:description" content="Learn HTML step by step">
<meta property="og:image" content="https://example.com/cover.png">
```

> 💡 **Interview tip:** Use an absolute URL for social preview images.

---

<a id="html-q084"></a>
### Q084. How do you add a favicon?

**✅ Easy answer:** A favicon is a small icon associated with a website, often displayed in browser tabs or bookmarks. Specify it in the document head.

**💻 Example:**

```html
<link rel="icon" href="/favicon.svg" type="image/svg+xml">
```

> 💡 **Interview tip:** Provide suitable fallback icon formats when supporting older browsers.

---

<a id="html-q085"></a>
### Q085. What does `rel="preload"` do?

**✅ Easy answer:** Preload tells the browser to fetch a resource needed soon, such as an important font, earlier in the loading process.

**💻 Example:**

```html
<link rel="preload" href="/fonts/site.woff2" as="font" type="font/woff2" crossorigin>
```

> 💡 **Interview tip:** Preload only resources that are truly needed early.

---

<a id="html-q086"></a>
### Q086. What does `rel="preconnect"` do?

**✅ Easy answer:** It lets the browser start connection setup to an important third-party origin earlier. It can reduce latency for resources fetched from that origin.

**💻 Example:**

```html
<link rel="preconnect" href="https://fonts.example.com" crossorigin>
```

> 💡 **Interview tip:** Avoid preconnecting to many unnecessary hosts.

---

<a id="html-q087"></a>
### Q087. How can you make images responsive?

**✅ Easy answer:** Use flexible CSS dimensions and provide alternate image sources when needed. The image should shrink within its container without losing its aspect ratio.

**💻 Example:**

```html
<img src="team.jpg" alt="Our engineering team" style="max-width:100%;height:auto">
```

> 💡 **Interview tip:** Prefer a reusable CSS class over inline styles in real projects.

---

<a id="html-q088"></a>
### Q088. Why specify `width` and `height` on images?

**✅ Easy answer:** These attributes help browsers reserve the expected image space before loading. Correct dimensions can reduce layout shifts.

**💻 Example:**

```html
<img src="avatar.jpg" width="200" height="200" alt="Profile photograph">
```

> 💡 **Interview tip:** For responsive designs, pair intrinsic dimensions with `max-width:100%;height:auto`.

---

<a id="html-q089"></a>
### Q089. When should you use `fetchpriority="high"`?

**✅ Easy answer:** It is a browser hint to prioritise an important resource, often the primary visible image. Using high priority for everything reduces its usefulness.

**💻 Example:**

```html
<img src="hero.jpg" alt="Course banner" width="1200" height="600" fetchpriority="high">
```

> 💡 **Interview tip:** Prioritise only genuinely critical above-the-fold assets.

---

<a id="html-q090"></a>
### Q090. Can an HTML meta tag replace all HTTP security headers?

**✅ Easy answer:** No. Some policies, like a limited Content Security Policy, can be placed in a meta tag, but several security headers must be sent as HTTP response headers.

**💻 Example:**

```html
<meta http-equiv="Content-Security-Policy" content="default-src 'self'; img-src 'self' data:">
```

> 💡 **Interview tip:** Configure critical security policies on the server whenever possible.

### Q091. How do you safely open a link in a new tab?

**✅ Easy answer:** Add `target="_blank"`. Explicit `rel="noopener noreferrer"` is a useful defence-in-depth choice, especially for compatibility and referrer privacy.

<a id="html-q092"></a>
### Q092. How can a link trigger a download?

**✅ Easy answer:** Use the `download` attribute on an `a` element. It works most reliably for same-origin URLs and certain browser-supported URL types.

**💻 Example:**

```html
<a href="/files/guide.pdf" download="html-guide.pdf">Download guide</a>
```

> 💡 **Interview tip:** For cross-origin files, browser behaviour and response headers may affect downloads.

<a id="html-q093"></a>
### Q093. How do `mailto:` and `tel:` links work?

**✅ Easy answer:** They ask the device to open an email or phone application. They are useful on contact pages and mobile-friendly sites.

**💻 Example:**

```html
<a href="mailto:hello@example.com">Email us</a>
<a href="tel:+911234567890">Call us</a>
```

> 💡 **Interview tip:** A device must have a compatible app for these schemes to work.

---

<a id="html-q094"></a>
### Q094. How do you build an accessible card with a link?

```html
<article>

```

> 💡 **Interview tip:** Avoid nesting buttons inside links.

---

<a id="html-q095"></a>
### Q095. How can you make a FAQ accordion without JavaScript?

**✅ Easy answer:** Native `details` and `summary` give you a keyboard-friendly show/hide interaction. Each question can be one `details` block.

**💻 Example:**

```html
<details>
  <summary>Is HTML hard to learn?</summary>
  <p>No. Start with semantic elements and forms.</p>
</details>
```

> 💡 **Interview tip:** For simple FAQs, native disclosure is easier to maintain.

---

<a id="html-q096"></a>
### Q096. How do you show a required field's error without a framework?

**✅ Easy answer:** Start with native validation attributes such as `required` and a suitable `type`. Browsers can block invalid submission and show built-in feedback.

**💻 Example:**

```html
<form>
  <label for="work-email">Work email</label>
  <input id="work-email" name="email" type="email" required>
  <button>Submit</button>
</form>
```

> 💡 **Interview tip:** Provide server-side validation and helpful error handling too.

---

<a id="html-q097"></a>
### Q097. How do you choose between `srcset` and `<picture>`?

**✅ Easy answer:** Use `srcset` for different sizes of the same image, and `picture` when the content or crop should change at different sizes.

**💻 Example:**

```html
<picture>
  <source media="(max-width: 600px)" srcset="banner-mobile.jpg">
  <img src="banner-wide.jpg" alt="Students learning HTML">
</picture>
```

> 💡 **Interview tip:** Art direction is a typical `picture` use case.

---

<a id="html-q098"></a>
### Q098. How can you prevent layout shift for embedded media?

**✅ Easy answer:** Give media an aspect ratio or known dimensions so the page reserves space before loading. CSS can then make the content responsive.

**💻 Example:**

```html
<iframe src="/demo" title="Product demo" width="560" height="315" style="max-width:100%;aspect-ratio:16/9"></iframe>
```

> 💡 **Interview tip:** For flexible layouts, set an appropriate height strategy alongside the aspect ratio.

---

<a id="html-q099"></a>
### Q099. How can you embed a video without making it autoplay?

**✅ Easy answer:** Embed a native player with `controls` and omit `autoplay`. Visitors can decide when to play, which is better for usability.

**💻 Example:**

```html
<video controls preload="metadata" width="640">
  <source src="lesson.mp4" type="video/mp4">
</video>
```

> 💡 **Interview tip:** `preload` is a hint; browsers may choose a different loading strategy.

---

<a id="html-q100"></a>
### Q100. How would you structure a small blog page semantically?

**✅ Easy answer:** Use landmarks for the page, `article` for the post, logical headings, and a footer for supporting details. The structure remains useful even without CSS.

**💻 Example:**

```html
<header><h1>My Blog</h1></header>
<main><article><h2>Learning HTML</h2><p>Start here.</p></article></main>
<footer>© Code with Jamshed</footer>
```

> 💡 **Interview tip:** Interviewers often value semantic structure more than decorative markup.

<a id="css-topic-01"></a>
## 🎨 CSS3 Topic 01: CSS Basics & Cascade

<sub>Questions 001–010 · [Back to contents](#table-of-contents)</sub>

<a id="css-q001"></a>
### Q001. What is CSS, and why is it used?

**✅ Easy answer:** CSS means Cascading Style Sheets. It controls the appearance of HTML, such as colours, fonts, spacing and layouts. One stylesheet can style many pages consistently.

**💻 Example:**

```css
h1 { color: #123c68; }
p { line-height: 1.6; }
```

> 💡 **Interview tip:** HTML provides meaning; CSS provides presentation.

---

<a id="css-q002"></a>
### Q002. What are the three ways to apply CSS?

**✅ Easy answer:** You can use an external stylesheet, an internal `style` block or inline styles. External CSS is generally preferred for shared, maintainable application styles.

**💻 Example:**

```html
<link rel="stylesheet" href="styles.css">
<style>p { color: navy; }</style>
<p style="font-weight: 700">Hello</p>
```

> 💡 **Interview tip:** Prefer external CSS for most project-level styling.

---

<a id="css-q003"></a>
### Q003. What is the syntax of a CSS rule?

**✅ Easy answer:** A CSS rule commonly has a selector and a declaration block. Each declaration has a property and its value.

**💻 Example:**

```css
.card {
  background: white;
  padding: 16px;
  border-radius: 12px;
}
```

> 💡 **Interview tip:** A semicolon separates declarations; the last one can be omitted but keeping it is clearer.

---

<a id="css-q004"></a>
### Q004. What is a CSS selector?

**✅ Easy answer:** A selector identifies which HTML elements should receive the declarations. You can target element names, classes, IDs, attributes or states.

**💻 Example:**

```css
p { color: #333; }
.highlight { background: #fff2b3; }
#banner { padding: 20px; }
```

> 💡 **Interview tip:** Classes are usually the most reusable choice for components.

---

<a id="css-q005"></a>
### Q005. What is CSS specificity?

**✅ Easy answer:** Specificity decides which declaration wins when competing rules have comparable cascade origin, importance, layer and scope. Roughly, ID selectors outweigh class selectors, which outweigh type selectors.

**💻 Example:**

```css
p { color: black; }
.note { color: blue; }
#important { color: red; }
```

> 💡 **Interview tip:** The cascade is bigger than specificity; source order, layers and importance also matter.

---

<a id="css-q006"></a>
### Q006. What does the cascade mean in CSS?

**✅ Easy answer:** The cascade determines the final winning declaration using origin, importance, layers, specificity, scope proximity and source order. It is why a later rule does not always win.

**💻 Example:**

```css
.message { color: blue; }
.message { color: green; } /* Green wins here */
```

> 💡 **Interview tip:** Source order is a tiebreaker only after higher-priority cascade rules are considered.

---

<a id="css-q007"></a>
### Q007. Which CSS properties are inherited?

**✅ Easy answer:** Some properties, like `color` and `font-family`, commonly inherit from a parent. Others, like `margin` and `border`, generally do not inherit.

**💻 Example:**

```css
body { color: #222; font-family: system-ui; }
section { border: 1px solid #ddd; }
```

> 💡 **Interview tip:** Check a property's inheritance behaviour instead of assuming all styles inherit.

---

<a id="css-q008"></a>
### Q008. When should `!important` be used?

**✅ Easy answer:** `!important` increases a declaration's priority within the cascade. It can solve special override cases but makes future maintenance harder when overused.

**💻 Example:**

```css
.warning { color: darkred !important; }
```

> 💡 **Interview tip:** Try better selectors, architecture or cascade layers before adding `!important`.

---

<a id="css-q009"></a>
### Q009. What is `box-sizing: border-box`?

**✅ Easy answer:** It makes declared `width` and `height` include the element's padding and border. This usually makes component sizing easier to predict.

**💻 Example:**

```css
*, *::before, *::after { box-sizing: border-box; }
.card { width: 300px; padding: 20px; border: 2px solid; }
```

> 💡 **Interview tip:** The margin still sits outside the declared width.

---

<a id="css-q010"></a>
### Q010. How do CSS comments work?

**✅ Easy answer:** A CSS comment begins with `/*` and ends with `*/`. Use comments to explain non-obvious decisions; comments are not rendered on the page.

**💻 Example:**

```css
/* Keep buttons easy to tap */
button { min-height: 44px; }
```

> 💡 **Interview tip:** Comments are visible in delivered stylesheets, so do not place secrets in them.

<a id="css-topic-02"></a>
## 🎨 CSS3 Topic 02: Selectors & Pseudo-Classes

<sub>Questions 011–020 · [Back to contents](#table-of-contents)</sub>

<a id="css-q011"></a>
### Q011. How is a class selector different from an ID selector?

**✅ Easy answer:** Classes can be shared across many elements and are good for reusable styles. IDs should be unique within a document and have higher selector specificity.

**💻 Example:**

```css
.button { padding: 10px 16px; }
#checkout { background: teal; }
```

> 💡 **Interview tip:** Use classes for most component styling.

---

<a id="css-q012"></a>
### Q012. What is the difference between descendant and child combinators?

**✅ Easy answer:** `A B` selects matching descendants at any nesting depth. `A > B` selects only direct children of `A`.

**💻 Example:**

```css
.menu a { color: navy; }
.menu > a { font-weight: bold; }
```

> 💡 **Interview tip:** Use child combinators when deep nested matches would cause problems.

---

<a id="css-q013"></a>
### Q013. What are adjacent and general sibling selectors?

**✅ Easy answer:** `A + B` matches a B immediately after A. `A ~ B` matches following B siblings of A that share the same parent.

**💻 Example:**

```css
h2 + p { margin-top: 0; }
h2 ~ p { color: #444; }
```

> 💡 **Interview tip:** These combinators only work with siblings, not arbitrary descendants.

---

<a id="css-q014"></a>
### Q014. What is an attribute selector?

**✅ Easy answer:** An attribute selector matches elements based on the presence or value of an HTML attribute. It is helpful for states and specific links.

**💻 Example:**

```css
input[required] { border-left: 3px solid orange; }
a[href^="https://"] { text-decoration: underline; }
```

> 💡 **Interview tip:** Do not rely on attribute-only styling when a class would be clearer.

---

<a id="css-q015"></a>
### Q015. What is a pseudo-class?

**✅ Easy answer:** A pseudo-class matches an element in a particular state or structural position, such as `:hover`, `:focus-visible` or `:first-child`.

**💻 Example:**

```css
button:hover { background: #dfefff; }
button:focus-visible { outline: 3px solid royalblue; }
```

> 💡 **Interview tip:** Support focus and touch users, not only hover users.

---

<a id="css-q016"></a>
### Q016. What is a pseudo-element?

**✅ Easy answer:** A pseudo-element styles a selected part of an element or generates decorative content, such as `::before`, `::after` and `::first-line`.

**💻 Example:**

```css
.badge::before { content: "★ "; color: goldenrod; }
```

> 💡 **Interview tip:** Important information should remain in HTML, not only in `content`.

---

<a id="css-q017"></a>
### Q017. How does `:not()` work?

**✅ Easy answer:** `:not()` excludes elements matching its selector argument. It is useful for exceptions without adding an extra helper class.

**💻 Example:**

```css
.list-item:not(.active) { opacity: .6; }
```

> 💡 **Interview tip:** Keep exclusions simple so selectors remain readable.

---

<a id="css-q018"></a>
### Q018. What is the difference between `:is()` and `:where()`?

**✅ Easy answer:** Both group selector alternatives. `:is()` takes specificity from its most specific argument, while `:where()` always contributes zero specificity.

**💻 Example:**

```css
:is(h1, h2, h3) { line-height: 1.2; }
:where(.card a) { color: teal; }
```

> 💡 **Interview tip:** `:where()` is useful for easy-to-override defaults.

---

<a id="css-q019"></a>
### Q019. What is the `:has()` pseudo-class?

**✅ Easy answer:** `:has()` can select an element based on matching descendants or other relative selectors. For example, a card can change when it contains an invalid input.

**💻 Example:**

```css
.field:has(input:invalid) { border-color: crimson; }
```

> 💡 **Interview tip:** Test cross-browser support appropriate to your audience and keep selectors efficient.

---

<a id="css-q020"></a>
### Q020. How does `:nth-child()` work?

**✅ Easy answer:** `:nth-child()` matches siblings based on their positions. It can target even/odd rows or recurring patterns without adding classes to each element.

**💻 Example:**

```css
tr:nth-child(even) { background: #f3f6fb; }
li:nth-child(3) { font-weight: bold; }
```

> 💡 **Interview tip:** `:nth-child()` counts all element siblings in the matching set's parent.

## 🎨 CSS3 Topic 03: Box Model & Visual Layout

<sub>Questions 021–030 · [Back to contents](#table-of-contents)</sub>

<a id="css-q021"></a>
### Q021. What is the CSS box model?

**✅ Easy answer:** Each rendered element can have content, padding, border and margin. Understanding these layers helps you debug size and spacing issues.

**💻 Example:**

```css
.box { width: 200px; padding: 20px; border: 2px solid; margin: 12px; }
```

> 💡 **Interview tip:** With default `content-box`, total rendered width exceeds 200px.

---

<a id="css-q022"></a>
### Q022. What is margin collapsing?

**✅ Easy answer:** Under certain normal block-flow conditions, adjoining vertical margins can combine into a single margin instead of adding together. Flex and grid item margins do not collapse this way.

**💻 Example:**

```css
.first { margin-bottom: 30px; }
.second { margin-top: 20px; }
/* In suitable normal block flow, the gap may be 30px. */
```

> 💡 **Interview tip:** Use `gap` with flex/grid layouts for more predictable spacing.

---

<a id="css-q023"></a>
### Q023. How is padding different from margin?

**✅ Easy answer:** Padding adds space inside the border, while margin adds space outside. Backgrounds generally paint over padding but not margins.

**💻 Example:**

```css
.card { padding: 24px; margin: 16px; background: #fff8da; }
```

> 💡 **Interview tip:** Use padding for inner breathing room and margin/gap for outer separation.

---

<a id="css-q024"></a>
### Q024. How does the `display` property work?

**✅ Easy answer:** `display` controls the type of layout box an element generates and how it participates in layout. Common values include `block`, `inline`, `flex`, `grid` and `none`.

**💻 Example:**

```css
.toolbar { display: flex; }
.hidden { display: none; }
```

> 💡 **Interview tip:** `display:none` removes the element from layout and generally from the accessibility tree.

---

<a id="css-q025"></a>
### Q025. What is the difference between `block`, `inline` and `inline-block`?

**✅ Easy answer:** Block elements generally start a new line. Inline elements flow with text and ignore some box dimensions, while inline-block retains inline flow with box sizing control.

**💻 Example:**

```css
.chip { display: inline-block; padding: 6px 12px; width: 90px; }
```

> 💡 **Interview tip:** Use inline-block for small width-controlled items within text flow.

---

<a id="css-q026"></a>
### Q026. What does `overflow` control?

**✅ Easy answer:** `overflow` controls what happens when content exceeds an element's box. Common values are `visible`, `hidden`, `auto` and `scroll`.

**💻 Example:**

```css
.code-panel { max-height: 220px; overflow: auto; }
```

> 💡 **Interview tip:** Make scrollable regions keyboard accessible when needed.

---

<a id="css-q027"></a>
### Q027. Why use `max-width` with `width`?

**✅ Easy answer:** `width` sets a desired width, while `max-width` caps it. The combination lets a layout fill small screens without becoming too wide on large displays.

**💻 Example:**

```css
.container { width: 100%; max-width: 1100px; margin-inline: auto; }
```

> 💡 **Interview tip:** With border-box sizing, container widths are easier to manage.

---

<a id="css-q028"></a>
### Q028. What is the difference between `min-height` and `height`?

**✅ Easy answer:** `height` suggests a fixed box height, while `min-height` lets the box grow if its content needs more room. This is helpful for accessible text resizing.

**💻 Example:**

```css
.hero { min-height: 320px; padding: 40px; }
```

> 💡 **Interview tip:** Avoid fixed heights when content length is unpredictable.

---

<a id="css-q029"></a>
### Q029. How does `object-fit` work?

**✅ Easy answer:** `object-fit` controls how replaced content like images fits within its own dimensions. `cover` fills and crops; `contain` shows everything with possible empty space.

**💻 Example:**

```css
.avatar { width: 80px; height: 80px; object-fit: cover; border-radius: 50%; }
```

> 💡 **Interview tip:** `object-position` controls which part remains visible when cropping.

---

<a id="css-q030"></a>
### Q030. What is the `aspect-ratio` property?

**✅ Easy answer:** It defines the preferred width-to-height ratio of a box. It is useful for responsive cards, media frames and placeholder areas.

**💻 Example:**

```css
.video-frame { width: 100%; aspect-ratio: 16 / 9; }
```

> 💡 **Interview tip:** If both width and height are explicitly fixed, the ratio may not control final dimensions.

---

## 🎨 CSS3 Topic 04: Positioning & Stacking

<sub>Questions 031–040 · [Back to contents](#table-of-contents)</sub>

<a id="css-q031"></a>
### Q031. What does `position: static` mean?

**✅ Easy answer:** Static is the default positioning mode. The element follows normal layout flow and offset properties such as `top` do not position it.

**💻 Example:**

```css
.item { position: static; top: 20px; }
/* 'top' has no positioning effect here. */
```

> 💡 **Interview tip:** Use static unless another positioning mode is actually needed.

---

<a id="css-q032"></a>
### Q032. What does `position: relative` do?

**✅ Easy answer:** Relative positioning keeps the element's original place in normal flow but allows visual offsets. It can also establish a containing block for positioned descendants.

**💻 Example:**

```css
.card { position: relative; }
.badge { position: absolute; top: 8px; right: 8px; }
```

> 💡 **Interview tip:** Relative positioning does not automatically remove an element from flow.

---

<a id="css-q033"></a>
### Q033. How does `position: absolute` work?

**✅ Easy answer:** Absolutely positioned elements are removed from normal flow. Their offsets are calculated relative to an appropriate containing block, often a positioned ancestor.

**💻 Example:**

```css
.photo { position: relative; }
.photo__label { position: absolute; bottom: 8px; left: 8px; }
```

> 💡 **Interview tip:** Give the intended ancestor `position:relative` when appropriate.

---

<a id="css-q034"></a>
### Q034. What does `position: fixed` do?

**✅ Easy answer:** A fixed-position element normally stays aligned to the viewport when scrolling. Certain ancestor properties can change the containing block in special cases.

**💻 Example:**

```css
.help-button { position: fixed; right: 20px; bottom: 20px; }
```

> 💡 **Interview tip:** Make sure fixed UI does not cover form fields or mobile controls.

---

<a id="css-q035"></a>
### Q035. What does `position: sticky` do?

**✅ Easy answer:** A sticky element behaves like a relatively positioned element until its scroll threshold is reached, then sticks within its scrolling area.

**💻 Example:**

```css
.table-heading { position: sticky; top: 0; background: white; }
```

> 💡 **Interview tip:** Sticky usually needs an inset such as `top:0` and enough space to scroll.

---

<a id="css-q036"></a>
### Q036. What is `z-index`?

**✅ Easy answer:** `z-index` controls paint order for relevant positioned or stacking-context elements. A larger value does not always win across different stacking contexts.

**💻 Example:**

```css
.overlay { position: fixed; z-index: 100; }
.tooltip { position: absolute; z-index: 110; }
```

> 💡 **Interview tip:** Inspect parent stacking contexts when z-index seems broken.

---

<a id="css-q037"></a>
### Q037. What creates a stacking context?

**✅ Easy answer:** Several properties create isolated stacking contexts, such as a positioned element with non-auto `z-index`, `transform`, and opacity below 1. Child z-index values stay within their context.

**💻 Example:**

```css
.panel { transform: translateZ(0); }
.panel__menu { position: absolute; z-index: 9999; }
```

> 💡 **Interview tip:** A huge child z-index cannot always escape its parent's stacking context.

---

<a id="css-q038"></a>
### Q038. What is the difference between `transform` and layout offsets?

**✅ Easy answer:** Transforms change visual rendering without moving surrounding boxes in the normal layout calculation. Properties like margin and positional offsets can affect layout differently.

**💻 Example:**

```css
.card:hover { transform: translateY(-4px); }
```

> 💡 **Interview tip:** Transforms are often smoother for small visual animations.

---

<a id="css-q039"></a>
### Q039. How do you centre a box horizontally and vertically?

**✅ Easy answer:** Flexbox is a simple way to centre a child in both directions. The parent's dimensions must leave enough room for centring to be visible.

**💻 Example:**

```css
.wrapper { display: flex; justify-content: center; align-items: center; min-height: 300px; }
```

> 💡 **Interview tip:** For a two-dimensional layout, CSS Grid can also use `place-items:center`.

---

<a id="css-q040"></a>
### Q040. What does `pointer-events: none` do?

**✅ Easy answer:** For HTML elements, it prevents that element from being the direct pointer-event target. It does not automatically disable keyboard interaction or everything inside the element.

**💻 Example:**

```css
.decorative-overlay { pointer-events: none; }
```

> 💡 **Interview tip:** Do not treat `pointer-events:none` as a replacement for disabling a control.

---

<a id="css-topic-05"></a>
## 🎨 CSS3 Topic 05: Flexbox Deep Dive

<sub>Questions 041–050 · [Back to contents](#table-of-contents)</sub>

<a id="css-q041"></a>
### Q041. What is Flexbox?

**✅ Easy answer:** Flexbox is a one-dimensional layout system for arranging items along a row or column. It is useful for toolbars, menus and small component layouts.

**💻 Example:**

```css
.nav { display: flex; gap: 16px; }
```

> 💡 **Interview tip:** Choose Flexbox when one direction is your main concern.

---

<a id="css-q042"></a>
### Q042. What does `flex-direction` do?

**✅ Easy answer:** It sets the main axis of a flex container. `row` lays items horizontally in typical writing modes; `column` stacks them vertically.

**💻 Example:**

```css
.sidebar { display: flex; flex-direction: column; }
```

> 💡 **Interview tip:** Main-axis properties change meaning when direction changes.

---

<a id="css-q043"></a>
### Q043. How does `justify-content` work in Flexbox?

**✅ Easy answer:** It distributes free space along the main axis, for example with `center`, `space-between` or `flex-end`.

**💻 Example:**

```css
.actions { display: flex; justify-content: space-between; }
```

> 💡 **Interview tip:** `justify-content` does not control the cross axis in Flexbox.

---

<a id="css-q044"></a>
### Q044. What does `align-items` do?

**✅ Easy answer:** It aligns flex items on the cross axis within each flex line. Values include `stretch`, `center`, `flex-start` and `baseline`.

**💻 Example:**

```css
.toolbar { display: flex; align-items: center; }
```

> 💡 **Interview tip:** It is useful for vertically aligning icons and text in a row.

---

<a id="css-q045"></a>
### Q045. How is `align-content` different from `align-items`?

**✅ Easy answer:** `align-content` distributes space between flex lines and matters when wrapping creates multiple lines and cross-axis space exists. `align-items` aligns items within each line.

**💻 Example:**

```css
.tags { display: flex; flex-wrap: wrap; align-content: space-between; min-height: 180px; }
```

> 💡 **Interview tip:** `align-content` often appears to do nothing when there is only one flex line.

---

<a id="css-q046"></a>
### Q046. Can you use `gap` in Flexbox?

**✅ Easy answer:** Yes. `gap` creates consistent space between flex items without adding margins to every child. It works with both rows and columns.

**💻 Example:**

```css
.buttons { display: flex; gap: 12px; flex-wrap: wrap; }
```

> 💡 **Interview tip:** Prefer `gap` for spacing between sibling layout items.

---

<a id="css-q047"></a>
### Q047. What does `flex-grow` do?

**✅ Easy answer:** `flex-grow` controls how items share positive leftover space along the main axis. A larger growth factor takes a larger share of that available space.

**💻 Example:**

```css
.layout { display: flex; }
.content { flex-grow: 1; }
```

> 💡 **Interview tip:** `flex-grow:1` does not guarantee equal total widths if base sizes differ.

---

<a id="css-q048"></a>
### Q048. What does `flex-shrink` do?

**✅ Easy answer:** `flex-shrink` controls how flex items reduce size when there is not enough room. The actual shrink calculation also considers each item's base size.

**💻 Example:**

```css
.logo { flex-shrink: 0; }
.search { flex-shrink: 1; min-width: 0; }
```

> 💡 **Interview tip:** `min-width:0` often fixes text overflow inside flex items.

---

<a id="css-q049"></a>
### Q049. What does `flex-basis` mean?

**✅ Easy answer:** `flex-basis` sets the initial main-axis size used by Flexbox before distributing extra or missing space. It can be a length, percentage or `auto`.

**💻 Example:**

```css
.column { flex: 1 1 240px; }
/* grow:1, shrink:1, basis:240px */
```

> 💡 **Interview tip:** Understand the `flex` shorthand: grow, shrink, basis.

---

<a id="css-q050"></a>
### Q050. What does the Flexbox `order` property do?

**✅ Easy answer:** `order` changes the visual order of flex items but does not change the DOM reading or keyboard focus order. This can confuse assistive technology users.

**💻 Example:**

```css
.featured { order: -1; }
```

> 💡 **Interview tip:** Keep important reading and interaction order correct in HTML.

---

## 🎨 CSS3 Topic 06: CSS Grid Deep Dive

<sub>Questions 051–060 · [Back to contents](#table-of-contents)</sub>

<a id="css-q051"></a>
### Q051. What is CSS Grid?

**✅ Easy answer:** Grid is a two-dimensional layout system that can control rows and columns together. It is useful for dashboards, galleries and complex page sections.

**💻 Example:**

```css
.dashboard { display: grid; grid-template-columns: 240px 1fr; gap: 20px; }
```

> 💡 **Interview tip:** Use Grid for two-dimensional control, Flexbox for one-dimensional flows.

---

<a id="css-q052"></a>
### Q052. What does `grid-template-columns` do?

**✅ Easy answer:** It defines the explicit column tracks of a grid. You can use fixed lengths, percentages, `fr` units and functions such as `minmax()`.

**💻 Example:**

```css
.cards { display: grid; grid-template-columns: 1fr 1fr 1fr; gap: 16px; }
```

> 💡 **Interview tip:** Tracks belong to the grid container, not the individual items.

---

<a id="css-q053"></a>
### Q053. What does the `fr` unit mean?

**✅ Easy answer:** `fr` represents a fraction of the available space in a grid container after relevant sizing calculations. It helps create flexible columns.

**💻 Example:**

```css
.layout { display: grid; grid-template-columns: 1fr 2fr; }
```

> 💡 **Interview tip:** For shrinkable content columns, `minmax(0, 1fr)` can prevent overflow.

---

<a id="css-q054"></a>
### Q054. How does `minmax()` help in Grid?

**✅ Easy answer:** `minmax(min, max)` sets an allowed sizing range for a grid track. It can combine a minimum track width with flexible growth.

**💻 Example:**

```css
.grid { display: grid; grid-template-columns: repeat(3, minmax(0, 1fr)); }
```

> 💡 **Interview tip:** `minmax(0,1fr)` is handy when long text would otherwise stretch columns.

---

<a id="css-q055"></a>
### Q055. What is the difference between `auto-fit` and `auto-fill`?

**✅ Easy answer:** Both repeat tracks according to available space. `auto-fill` retains empty tracks, while `auto-fit` collapses unused repeated tracks so occupied tracks can grow.

**💻 Example:**

```css
.cards { display: grid; grid-template-columns: repeat(auto-fit, minmax(220px, 1fr)); gap: 16px; }
```

> 💡 **Interview tip:** Use `auto-fit` for flexible cards that should stretch when fewer cards exist.

---

<a id="css-q056"></a>
### Q056. What does `grid-area` do?

**✅ Easy answer:** `grid-area` can name an item for a grid template or specify its row/column placement. Named areas make page layouts easy to read.

**💻 Example:**

```css
.page { display:grid; grid-template-areas: "head head" "side main"; grid-template-columns:200px 1fr; }
.header { grid-area:head; }
.sidebar { grid-area:side; }
.main { grid-area:main; }
```

> 💡 **Interview tip:** Each named area's cells must form a rectangle.

---

<a id="css-q057"></a>
### Q057. How can an item span multiple grid columns?

**✅ Easy answer:** Use `grid-column` with line positions or the `span` keyword. This is useful for featured cards that should cover more than one track.

**💻 Example:**

```css
.featured { grid-column: span 2; }
```

> 💡 **Interview tip:** Consider how a spanning item behaves on narrow screens.

---

<a id="css-q058"></a>
### Q058. What is the implicit grid?

**✅ Easy answer:** When items need rows or columns beyond those explicitly defined, CSS Grid creates implicit tracks. You can size them with `grid-auto-rows` or `grid-auto-columns`.

**💻 Example:**

```css
.gallery { display:grid; grid-template-columns:repeat(3,1fr); grid-auto-rows:180px; }
```

> 💡 **Interview tip:** Implicit rows are common when the number of cards changes dynamically.

---

<a id="css-q059"></a>
### Q059. How do `justify-items` and `align-items` work in Grid?

**✅ Easy answer:** `justify-items` aligns grid items on the inline axis of their cells; `align-items` handles the block axis. `place-items` can set both together.

**💻 Example:**

```css
.gallery { display:grid; place-items:center; }
```

> 💡 **Interview tip:** Do not confuse item alignment with distribution of the full grid tracks.

---

<a id="css-q060"></a>
### Q060. When should you choose Grid instead of Flexbox?

**✅ Easy answer:** Use Grid when you need coordinated rows and columns, and Flexbox when content flows mainly in one dimension. You can combine both in one design.

**💻 Example:**

```css
.page { display:grid; grid-template-columns:220px 1fr; }
.toolbar { display:flex; gap:12px; }
```

> 💡 **Interview tip:** Real applications often use Grid for page structure and Flexbox inside components.

---

## 🎨 CSS3 Topic 07: Responsive Design & Modern Units

<sub>Questions 061–070 · [Back to contents](#table-of-contents)</sub>

<a id="css-q061"></a>
### Q061. What is responsive web design?

**✅ Easy answer:** Responsive design adapts content to different viewports, input modes and user settings. Flexible sizing, sensible layout and media/container queries make pages usable on many devices.

**💻 Example:**

```css
.content { width:min(100% - 32px, 1100px); margin-inline:auto; }
```

> 💡 **Interview tip:** Design for content and usability, not for only one phone model.

---

<a id="css-q062"></a>
### Q062. What is a CSS media query?

**✅ Easy answer:** A media query applies rules only when a device or environment matches conditions such as viewport width or reduced motion preferences.

**💻 Example:**

```css
@media (max-width: 600px) {
  .sidebar { display:none; }
}
```

> 💡 **Interview tip:** Test whether hiding content removes essential functionality.

---

<a id="css-q063"></a>
### Q063. How do you choose responsive breakpoints?

**✅ Easy answer:** Pick breakpoints where your content stops working well, not simply popular device widths. Content-driven breakpoints stay useful across many screens.

**💻 Example:**

```css
@media (min-width: 48rem) {
  .cards { grid-template-columns:repeat(2,1fr); }
}
```

> 💡 **Interview tip:** Start with the smallest comfortable layout and expand when needed.

---

<a id="css-q064"></a>
### Q064. What is mobile-first CSS?

**✅ Easy answer:** Mobile-first styling starts with a simple layout for narrow screens, then adds enhancements using `min-width` media queries as more space becomes available.

**💻 Example:**

```css
.cards { display:grid; grid-template-columns:1fr; }
@media (min-width: 48rem) { .cards { grid-template-columns:repeat(3,1fr); } }
```

> 💡 **Interview tip:** Mobile-first often makes default styles cleaner.

---

<a id="css-q065"></a>
### Q065. What are CSS container queries?

**✅ Easy answer:** Container queries let a component adapt to the size of its containing element, not just the entire viewport. This is very useful for reusable cards.

**💻 Example:**

```css
.card-shell { container-type:inline-size; }
@container (min-width: 500px) { .card { display:flex; gap:16px; } }
```

> 💡 **Interview tip:** Choose a query container above the element you want to style.

---

<a id="css-q066"></a>
### Q066. What is the difference between `em` and `rem`?

**✅ Easy answer:** `em` depends on the relevant element's font size context, while `rem` is relative to the root element's font size. Both help create scalable designs.

**💻 Example:**

```css
html { font-size:16px; }
.card { padding:1.5rem; }
.card h2 { font-size:1.5em; }
```

> 💡 **Interview tip:** `em` in a font-size declaration is based on the parent's computed font size.

---

<a id="css-q067"></a>
### Q067. What are viewport units like `vw`, `vh` and `dvh`?

**✅ Easy answer:** `vw` and `vh` are based on viewport dimensions, while dynamic viewport units such as `dvh` account for changing browser interface areas on mobile.

**💻 Example:**

```css
.hero { min-height:100dvh; padding:5vw; }
```

> 💡 **Interview tip:** Mobile browser toolbars can make plain `100vh` less convenient.

---

<a id="css-q068"></a>
### Q068. What is the CSS `clamp()` function?

**✅ Easy answer:** `clamp(min, preferred, max)` keeps a responsive value within chosen limits. It is useful for fluid font sizes and spacing.

**💻 Example:**

```css
h1 { font-size:clamp(1.8rem, 4vw, 3.5rem); }
```

> 💡 **Interview tip:** Fluid text should still remain readable at zoomed-in settings.

---

<a id="css-q069"></a>
### Q069. What are CSS custom properties?

**✅ Easy answer:** Custom properties start with `--` and are read using `var()`. They make reusable design tokens such as colours and spacing easy to maintain.

**💻 Example:**

```css
:root { --brand:#2457b2; }
button { background:var(--brand); color:white; }
```

> 💡 **Interview tip:** Custom properties follow the cascade and commonly inherit.

---

<a id="css-q070"></a>
### Q070. How do you detect the user's dark-mode preference?

**✅ Easy answer:** Use `prefers-color-scheme` in a media query to apply a dark theme when the user's system preference indicates dark mode.

**💻 Example:**

```css
body { background:white; color:#111; }
@media (prefers-color-scheme:dark) { body { background:#161616; color:white; } }
```

> 💡 **Interview tip:** Provide sufficient text contrast in both light and dark themes.

<a id="css-topic-08"></a>
## 🎨 CSS3 Topic 08: Colours, Fonts & Text

<sub>Questions 071–080 · [Back to contents](#table-of-contents)</sub>

<a id="css-q071"></a>
### Q071. Which colour formats can CSS use?

**✅ Easy answer:** CSS supports named colours, hexadecimal, `rgb()`, `hsl()` and newer colour spaces. Choose formats that suit readability and your design system.

**💻 Example:**

```css
.primary { color:#1e40af; }
.accent { color:hsl(18 80% 45%); }
```

> 💡 **Interview tip:** Consistent design tokens are more useful than mixing random colours.

---

<a id="css-q072"></a>
### Q072. What is the difference between `opacity` and alpha colours?

**✅ Easy answer:** `opacity` makes the whole element, including its content and descendants, translucent. An alpha channel in a background colour can make only that colour transparent.

**💻 Example:**

```css
.card { background:rgb(0 0 0 / 15%); }
.disabled-preview { opacity:.5; }
```

> 💡 **Interview tip:** Use alpha backgrounds when text should stay fully opaque.

---

<a id="css-q073"></a>
### Q073. What is a font stack?

**✅ Easy answer:** A font stack lists preferred fonts with fallback options. The browser chooses the first available font, helping text remain readable on different systems.

**💻 Example:**

```css
body { font-family:Inter, "Segoe UI", Arial, sans-serif; }
```

> 💡 **Interview tip:** Always end a font stack with an appropriate generic family.

---

<a id="css-q074"></a>
### Q074. What does `@font-face` do?

**✅ Easy answer:** `@font-face` registers a custom font family and points to its font file. You can then use that name in `font-family`.

**💻 Example:**

```css
@font-face { font-family:"SiteSans"; src:url("/fonts/site.woff2") format("woff2"); font-display:swap; }
body { font-family:"SiteSans", sans-serif; }
```

> 💡 **Interview tip:** Respect font licensing and optimise font file size.

---

<a id="css-q075"></a>
### Q075. How does `line-height` affect readability?

**✅ Easy answer:** `line-height` controls the height of a line box. A sensible unitless value generally improves paragraph readability and scales with font size.

**💻 Example:**

```css
body { font-size:1rem; line-height:1.6; }
```

> 💡 **Interview tip:** Unitless line-height is often easiest to maintain across nested text.

---

<a id="css-q076"></a>
### Q076. What does `font-weight` control?

**✅ Easy answer:** It controls the thickness of font strokes. Common values are `400` for normal and `700` for bold, depending on the font's available weights.

**💻 Example:**

```css
h2 { font-weight:700; }
.small-label { font-weight:500; }
```

> 💡 **Interview tip:** Not every font file provides every numeric weight.

---

<a id="css-q077"></a>
### Q077. How do you show a one-line ellipsis for long text?

**✅ Easy answer:** Use `overflow:hidden`, `white-space:nowrap` and `text-overflow:ellipsis` on a width-constrained element.

**💻 Example:**

```css
.title { max-width:260px; overflow:hidden; white-space:nowrap; text-overflow:ellipsis; }
```

> 💡 **Interview tip:** Do not hide essential information without an accessible way to read it.

---

<a id="css-q078"></a>
### Q078. What does the `white-space` property do?

**✅ Easy answer:** It controls how spaces, line breaks and wrapping are handled in text. `pre-wrap` preserves entered line breaks while allowing long lines to wrap.

**💻 Example:**

```css
.user-note { white-space:pre-wrap; overflow-wrap:anywhere; }
```

> 💡 **Interview tip:** For user-generated text, consider both line breaks and long unbroken words.

---

<a id="css-q079"></a>
### Q079. What is `:focus-visible` used for?

**✅ Easy answer:** It styles focus when the browser determines a visible indicator is useful, commonly during keyboard navigation. It helps keep interfaces usable without showing unnecessary focus rings on every mouse click.

**💻 Example:**

```css
button:focus-visible { outline:3px solid #2563eb; outline-offset:3px; }
```

> 💡 **Interview tip:** Never remove focus indicators without providing an effective replacement.

---

<a id="css-q080"></a>
### Q080. How do you style links without hurting accessibility?

**✅ Easy answer:** Keep links visually recognisable and provide a clear focus state. Avoid relying on colour alone where links may blend into surrounding text.

**💻 Example:**

```css
a { color:#1456a0; text-decoration:underline; }
a:focus-visible { outline:2px solid currentColor; }
```

> 💡 **Interview tip:** Contrast and visible focus states matter more than decorative effects.

<a id="css-topic-09"></a>
## 🎨 CSS3 Topic 09: Animation & Visual Effects

<sub>Questions 081–090 · [Back to contents](#table-of-contents)</sub>

<a id="css-q081"></a>
### Q081. What is a CSS transition?

**✅ Easy answer:** A transition animates the change between property values when an element's state changes. You can choose its duration, easing and delay.

**💻 Example:**

```css
button { background:#2563eb; transition:background-color .2s ease; }
button:hover { background:#1d4ed8; }
```

> 💡 **Interview tip:** Transitions are ideal for small UI state changes.

---

<a id="css-q082"></a>
### Q082. What is a CSS animation?

**✅ Easy answer:** An animation runs through named keyframes and can repeat or play once. Unlike transitions, it does not require a before/after interaction state.

**💻 Example:**

```css
.dot { animation:pulse 1s ease-in-out infinite alternate; }
@keyframes pulse { from { opacity:.3; } to { opacity:1; } }
```

> 💡 **Interview tip:** Avoid unnecessary infinite animations that distract users.

---

<a id="css-q083"></a>
### Q083. What does `@keyframes` do?

**✅ Easy answer:** `@keyframes` defines stages of an animation, using `from`/`to` or percentage points. Apply the sequence with the `animation` property.

**💻 Example:**

```css
@keyframes slideIn { from { transform:translateY(12px); opacity:0; } to { transform:translateY(0); opacity:1; } }
.notice { animation:slideIn .3s ease-out; }
```

> 💡 **Interview tip:** Keep motion short and purposeful.

---

<a id="css-q084"></a>
### Q084. Why animate `transform` and `opacity` when possible?

**✅ Easy answer:** These properties can often be animated efficiently without recalculating layout each frame. Real performance still depends on browser, device and page complexity.

**💻 Example:**

```css
.card { transition:transform .2s ease, opacity .2s ease; }
.card:hover { transform:translateY(-4px); }
```

> 💡 **Interview tip:** Measure performance rather than assuming every animation is cheap.

---

<a id="css-q085"></a>
### Q085. What is `prefers-reduced-motion`?

**✅ Easy answer:** It detects a user preference for less motion. You can reduce or remove non-essential animations to make your site more comfortable.

**💻 Example:**

```css
@media (prefers-reduced-motion:reduce) {
  *, *::before, *::after { animation-duration:.01ms !important; transition-duration:.01ms !important; }
}
```

> 💡 **Interview tip:** Keep essential state changes understandable without animation.

---

<a id="css-q086"></a>
### Q086. What is the `filter` property?

**✅ Easy answer:** `filter` applies visual effects, such as blur, grayscale or brightness, to an element's rendered content.

**💻 Example:**

```css
.photo { filter:grayscale(100%); }
.photo:hover { filter:grayscale(0%); }
```

> 💡 **Interview tip:** Heavy blur effects may affect performance on low-end devices.

---

<a id="css-q087"></a>
### Q087. What is `backdrop-filter`?

**✅ Easy answer:** It applies visual effects to what appears behind an element, usually combined with a semi-transparent background to create a frosted-glass look.

**💻 Example:**

```css
.glass { background:rgb(255 255 255 / 60%); backdrop-filter:blur(12px); }
```

> 💡 **Interview tip:** Provide a readable fallback because blur may not suit every device or browser.

---

<a id="css-q088"></a>
### Q088. How do you create a CSS gradient?

**✅ Easy answer:** A gradient is a generated image that blends colours. `linear-gradient()` is often used as a background without needing an external image file.

**💻 Example:**

```css
.hero { background:linear-gradient(120deg, #eff6ff, #fde7f3); }
```

> 💡 **Interview tip:** Always check text contrast on different parts of the gradient.

---

<a id="css-q089"></a>
### Q089. How do fallback values work in `var()`?

**✅ Easy answer:** The second argument of `var()` is used when the referenced custom property is missing or invalid for substitution. This helps components work without every variable being defined.

**💻 Example:**

```css
.button { background:var(--button-bg, #2563eb); }
```

> 💡 **Interview tip:** The fallback is not a general recovery mechanism for every invalid final declaration.

---

<a id="css-q090"></a>
### Q090. What is native CSS nesting?

**✅ Easy answer:** Modern CSS allows rules to be nested so closely related selectors can be grouped. It reduces repetition while keeping valid CSS structure.

**💻 Example:**

```css
.card {
  padding:1rem;
  & h2 { margin-top:0; }
  &:hover { box-shadow:0 4px 12px #0002; }
}
```

> 💡 **Interview tip:** Native nesting is CSS; it does not require Sass in modern browsers.

## 🎨 CSS3 Topic 10: Architecture, Debugging & Real Scenarios

<sub>Questions 091–100 · [Back to contents](#table-of-contents)</sub>

<a id="css-q091"></a>
### Q091. What is BEM naming in CSS?

**✅ Easy answer:** BEM is a convention using Block, Element and Modifier names. It helps teams write understandable selectors that avoid accidental collisions.

**💻 Example:**

```css
.card {}
.card__title {}
.card--featured {}
```

> 💡 **Interview tip:** A convention helps, but consistency matters more than one naming scheme.

---

<a id="css-q092"></a>
### Q092. What are CSS Modules?

**✅ Easy answer:** CSS Modules are a build-tool technique that scopes class names to a component or file, commonly used with React. They are not a feature built into plain HTML/CSS by themselves.

**💻 Example:**

```jsx
import styles from './Button.module.css';
export default function Button() {
  return <button className={styles.primary}>Save</button>;
}
```

> 💡 **Interview tip:** Configure CSS Modules in the framework or bundler you use.

---

<a id="css-q093"></a>
### Q093. What are CSS cascade layers (`@layer`)?

**✅ Easy answer:** Cascade layers let you control the precedence of groups of styles independently from selector specificity. They help organise resets, component rules and overrides.

**💻 Example:**

```css
@layer reset, components, utilities;
@layer components { .button { color:navy; } }
@layer utilities { .text-red { color:crimson; } }
```

> 💡 **Interview tip:** Among normal author declarations, later layers win over earlier layers.

---

<a id="css-q094"></a>
### Q094. What are logical properties in CSS?

**✅ Easy answer:** Logical properties describe directions based on text flow rather than fixed left/right sides. They help support languages that read in different directions.

**💻 Example:**

```css
.card { padding-inline:20px; margin-block:16px; border-inline-start:3px solid teal; }
```

> 💡 **Interview tip:** Prefer logical properties for internationalised layouts.

---

<a id="css-q095"></a>
### Q095. What does `:focus-within` do?

**✅ Easy answer:** It matches an element when it or one of its descendants has focus. You can highlight a whole form field group when an input is focused.

**💻 Example:**

```css
.field:focus-within { outline:2px solid #60a5fa; border-radius:6px; }
```

> 💡 **Interview tip:** Useful for accessible form container highlights.

---

<a id="css-q096"></a>
### Q096. How do you write print-specific CSS?

**✅ Easy answer:** Use `@media print` to adjust layout for printed pages, such as hiding unnecessary navigation and using legible colours.

**💻 Example:**

```css
@media print {
  nav, .no-print { display:none; }
  body { color:black; background:white; }
}
```

> 💡 **Interview tip:** Check the browser's print preview before publishing important documents.

---

<a id="css-q097"></a>
### Q097. What is `content-visibility`?

**✅ Easy answer:** `content-visibility` lets browsers skip some rendering work for off-screen sections, which may improve performance on long pages.

**💻 Example:**

```css
.long-article-section { content-visibility:auto; contain-intrinsic-size:auto 500px; }
```

> 💡 **Interview tip:** Test scrolling and accessibility behaviour before using it broadly.

---

<a id="css-q098"></a>
### Q098. What is CSS scroll snapping?

**✅ Easy answer:** Scroll snapping aligns scroll positions to specified points, which can help create horizontal card galleries and carousels.

**💻 Example:**

```css
.carousel { display:flex; overflow-x:auto; scroll-snap-type:x mandatory; gap:16px; }
.slide { scroll-snap-align:start; flex:0 0 85%; }
```

> 💡 **Interview tip:** Avoid trapping users in scroll experiences they cannot control.

---

<a id="css-q099"></a>
### Q099. How do you make a responsive card grid without many breakpoints?

**✅ Easy answer:** Use CSS Grid with `repeat(auto-fit, minmax(...))` to automatically fit as many cards as available space allows. A small `min()` prevents narrow-screen overflow.

**💻 Example:**

```css
.cards { display:grid; grid-template-columns:repeat(auto-fit, minmax(min(100%, 240px), 1fr)); gap:20px; }
```

> 💡 **Interview tip:** This pattern scales from mobile to desktop with little extra CSS.

---

<a id="css-q100"></a>
### Q100. How do you debug a style that is not applying?

**✅ Easy answer:** Inspect the element using browser DevTools. Check whether the selector matches, the property is valid, another declaration wins, or a parent layout constraint prevents the effect.

**💻 Example:**

```css
/* Example: this more specific rule may win */
#save { color:red; }
.button { color:blue; }
```

> 💡 **Interview tip:** Use the browser's Computed and Styles panels before adding `!important`.

# ⚡ Quick Revision Cheat Sheets

## HTML5: Important comparisons

| Concept A | Concept B | Remember this |
|---|---|---|
| `section` | `article` | Section = thematic grouping; article = self-contained item. |
| `div` | `span` | Generic block-level grouping vs generic inline grouping. |
| `strong` | `b` | Strong importance vs stylistic attention. |
| `em` | `i` | Stress emphasis vs alternate/offset voice. |
| `GET` | `POST` | GET parameters normally appear in URL; POST carries data in request body. |
| `disabled` | `readonly` | Disabled is usually excluded from submission; readonly text values are submitted. |
| `select` | `datalist` | Select a listed option vs receive suggestions while typing. |
| `progress` | `meter` | Task completion vs measurement inside a range. |
| `async` | `defer` | Async runs when ready; defer waits for parsing and preserves classic script order. |
| `srcset` | `picture` | Responsive candidates vs art-direction/source choices. |

## CSS3: Important comparisons

| Concept A | Concept B | Remember this |
|---|---|---|
| `margin` | `padding` | Outside the border vs inside the border. |
| `relative` | `absolute` | Keeps space in flow vs removed from normal flow. |
| `fixed` | `sticky` | Usually viewport-anchored vs sticks within its scroll area. |
| `em` | `rem` | Local font-size context vs root font-size. |
| Flexbox | Grid | One-dimensional vs two-dimensional layout control. |
| `justify-content` | `align-items` | Main-axis distribution vs cross-axis item alignment in Flexbox. |
| `auto-fit` | `auto-fill` | Can collapse empty tracks vs retains them. |
| `:is()` | `:where()` | Matching alternatives with normal specificity vs zero specificity. |
| `opacity` | alpha background | Translucent entire element vs selected colour. |
| `transition` | `animation` | Interpolates state change vs follows keyframe timeline. |

### 📝 CSS specificity — rapid reminder

For competing declarations **in the same cascade origin, importance and layer**, specificity commonly follows:

```text
ID selectors        #profile                  1-0-0
Class / attribute   .card, [required], :hover  0-1-0
Type selectors      h1, p, ::before           0-0-1
:where(...)         zero specificity          0-0-0
```

**Remember:** `!important`, cascade layers, inline styles, transitions, animations and cascade origins also matter. **A higher specificity selector does not automatically win every conflict.**

<a id="common-interview-mistakes"></a>
## 🚨 Common mistakes to avoid

- Using `<div>` for every element even when a semantic element exists.
- Relying only on placeholder text instead of proper labels.
- Using `type="number"` for phone numbers or codes with leading zeros.
- Forgetting that browser form validation is **not** server-side security.
- Removing focus outlines without a usable replacement.
- Assuming `z-index: 999999` always beats every other element.
- Using Flexbox `order` to change visual order while forgetting screen reader and focus order.
- Using fixed pixel dimensions for every responsive component.
- Using `!important` as the first solution to every styling conflict.
- Animating heavily without respecting reduced-motion preferences.
